# Security Policy

## Supported versions

Only the latest published release on the `main` branch receives security fixes. Please keep dependencies up to date; older versions will not be patched.

| Version | Supported |
|---|---|
| Latest published on `main` | Yes |
| Older versions | No |

## Reporting a vulnerability

Please report security vulnerabilities privately via [GitHub's private vulnerability reporting](https://github.com/yomotsu/camera-controls/security/advisories/new) rather than opening a public issue.

When reporting, please include:

- A description of the issue
- Steps to reproduce, or a minimal proof-of-concept
- The affected version(s)
- Any known mitigation or workaround

You should receive an acknowledgement within a reasonable time. Please do not disclose the issue publicly until a fix has been released.
